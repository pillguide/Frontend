# 스캔·내 약 최소 연결

실제 인증 API 계약으로 기존 스캔 화면의 타이머/mock 결과를 교체했다. 새 전용 이미지 비교 페이지의 디자인·구현과 대표 이미지 실표시는 포함하지 않는다.

- `POST /api/v1/scan`은 FormData의 file(JPEG/PNG, 최대10MiB)과 requestId UUID를 사용한다. 같은 사진 재시도는 같은 파일/ID, 재촬영은 새ID다. 서버의 픽셀 제한과 손상 검증은413/415로 표시한다. 임의 완료 시간이나 진행률을 표시하지 않는다.
- 원본 File·미리보기·분석 결과·선택은 메모리에만 보유한다. 현재 결과에 포함된 약 상세 화면에 갔다 돌아오는 동안 유지하며 흐름 이탈·재촬영·저장 건너뛰기·성공한 로그아웃 때 해제한다. 늦은 응답은 세대/마운트 검증으로 무시한다. 브라우저 새로고침 후 원본 사진은 복원하지 않는다.
- 결과 카드는 drugId가 아닌 영구 detectionId로 식별한다. A,A,B는3카드이고 병용 비교는 고유품목2개·1쌍이다. 선택을 바꿔도 전체 사진의 병용 결과는 바뀌지 않는다. 공식 자료/허가/갱신 지연 상태와 근거·기준일을 표시하며 미일치를 안전으로 표현하지 않는다.
- 선택 저장은 `{scanSessionId,detectionIds}`만 전달한다. `/my-drugs`의 제한된 목록·관계 제거를 연결하고 마이페이지에 진입점을 추가했다. 기존 홈·통계·복약 상태 전환은 포함하지 않는다.
- 이력은 당시 검출/병용 결과와 현재 약 상세를 구분한다. 기존 mock 약 상세 경로도 실제 API 화면으로 연결했다.
- 실제 데이터셋 이미지가 준비되기 전은 NOT_READY 자리표시자다. 이후 전용 비교 화면은 같은 업로드 사진의 EXIF 보정 크기를 AI imageSize와 대조하고 bbox 위치를 검증해야 한다. confidence는 정답 확률이 아니며 사용자에게 정답 확인을 요구하지 않는다.

검증: lint, Node12건, TypeScript/Vite build 통과. 실제 브라우저에서 통제된 API 응답으로 503 재시도/동일UUID/multipart/인증헤더/3검출/1조합/상세뒤로가기/선택저장/목록제거/사진비보관을 확인했다. 실제 DEV OAuth·프록시·대표 이미지 검증은 아직 별도 관문이다.
